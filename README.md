### 🚀 Projetos em Destaque

#### 🏥 Healthcare Lakehouse (Databricks)
*Simulação de uma arquitetura moderna de dados no setor de saúde suplementar utilizando o conceito de Lakehouse.*
- **O Problema de Negócio:**  Dados fragmentados entre diferentes sistemas (atendimentos, autorizações, faturamento), dificultando a geração de insights confiáveis, aumentando o tempo de análise e impactando diretamente a tomada de decisão estratégica.
- **A Solução:**  Construção de um pipeline de dados end-to-end no ambiente Databricks, utilizando a arquitetura medalhão (Bronze, Silver e Gold), garantindo qualidade, governança e organização dos dados ao longo do ciclo.
- **Abordagem Técnica:**  Ingestão de dados brutos → tratamento e padronização → modelagem analítica voltada para consumo de negócio.  
Uso de SQL e conceitos de engenharia de dados para estruturar camadas confiáveis e escaláveis dentro do Lakehouse.

- **Impacto:**  
Criação de uma base de dados estruturada e confiável, permitindo análises mais rápidas, consistentes e orientadas ao negócio, com potencial de aplicação em cenários reais como controle de custos, análise de sinistralidade e suporte à decisão estratégica.

#### 💳 Fraud Detection System (Loss Prevention)
*Este projeto simula um ambiente real de prevenção de fraudes em transações financeiras.*
- **O Problema de Negócio:** Reduzir prejuízos com *chargebacks* sem impactar a conversão de clientes legítimos (falso-positivos).
- **Abordagem Técnica:** Construção de um pipeline robusto em Python 3.12, utilizando PyArrow para performance e design focado em métricas de negócio.



#### 📈 Tech Vendas Global (Data Warehouse & BI)
